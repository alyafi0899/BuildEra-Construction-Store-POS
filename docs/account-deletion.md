# Account Deletion Request Flow

This project includes an app-level and web-level flow for data deletion requests.

## Support contact
- Email: wenyafi@gmail.com

## Web endpoints
- Privacy policy: https://alyafi0899.github.io/BuildEra-Construction-Store-POS/privacy-policy/
- Account deletion page: https://alyafi0899.github.io/BuildEra-Construction-Store-POS/account-deletion/

## Request process
1. User opens the Support & Privacy dialog from Settings.
2. User clicks `Hapus Akun` or sends an email to the support address.
3. Request is reviewed by the support team and processed within 30 days.
4. Account and related operational data are removed from the application data store as appropriate.

## Notes
- The app exposes these links via `lib/core/config/app_contacts.dart`.
- The static web pages live under `web/privacy-policy/` and `web/account-deletion/`.
